5S SMART ORDER – BẢN ONLINE ĐỒNG BỘ ĐƠN HÀNG

1. Tải nguyên file ZIP này lên Netlify bằng cách Deploy thủ công.
2. Mở link chính của website.
3. Khách quét QR hoặc mở /dat-hang để đặt hàng.
4. Nhà phân phối mở /quan-ly trên máy tính hoặc điện thoại.
5. Trang quản lý tự kiểm tra đơn mới mỗi 5 giây.

LƯU Ý QUAN TRỌNG
- Phải tải NGUYÊN gói ZIP để Netlify cài Functions và Netlify Blobs.
- Không chỉ tải riêng các file HTML.
- Cần mạng internet khi đặt hàng và nhận đơn.
- Giao diện quản lý đã được chỉnh để dùng trên điện thoại bằng thanh menu phía dưới.
